# Project Documentation

This folder contains the Milestone 1 documentation for the MarketStreet project.

## Documents

The following project documents will be stored here:

- Business Problem and Scope
- Stakeholders
- Main Transaction
- Functional and Nonfunctional Requirements
- User Stories and Acceptance Criteria
- Business Rules
- Team Charter

These documents define the project scope, transaction flow, requirements, business rules, and team responsibilities before implementation begins.
